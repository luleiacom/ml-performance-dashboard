# ML Performance & Monitoring Dashboard

Este proyecto implementa un sistema de monitoreo para modelos en producción, permitiendo visualizar la degradación del modelo y asegurar la calidad de las predicciones en tiempo real.

## Funcionalidades
* **Seguimiento de Accuracy:** Visualización histórica del desempeño del modelo.
* **Detección de Drift:** Identificación de momentos críticos que requieren re-entrenamiento.
* **Interfaz Visual:** Gráficos optimizados para la toma de decisiones ejecutivas.

## Stack
* **Lenguaje:** Python (Pandas, Matplotlib).
* **Entorno:** Google Colab / Jupyter Notebooks.
